# Reporting a Vulnerability

If you discover a security vulnerability related to the NEXARIUM infrastructure, semantic systems, identity layers, federated infrastructure, or associated services, please report it responsibly.

## Contact

Email:  
contact@nexarium.us

---

# Reporting Guidelines

Please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Affected infrastructure or domain
- Relevant screenshots or logs if applicable

---

# Responsible Disclosure

Please do not publicly disclose vulnerabilities before they have been reviewed and evaluated.

Responsible disclosure helps preserve infrastructure integrity and ecosystem security.
